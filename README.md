# Memorial Web

A simple memorial website to remember and honour loved ones, built with React.

## Live Demo
https://memorial-web.netlify.app

## About the Project
This website is a tribute page that shares memories, photos and messages in a clean and peaceful design. It works on both mobile and desktop.

## Features
- Photo gallery
- Memories and tribute messages
- Clean and simple design
- Responsive layout (mobile and laptop)

## Tech Stack
- React.js
- HTML, CSS, JavaScript
- Netlify (hosting)
- GitHub (version control)

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
4. Open http://localhost:3000 in your browser

## Build for Production
`npm run build`
